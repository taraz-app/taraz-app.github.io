کلید خواندن فاکتور از عکس

برای اینکه برنامه عکس فاکتور را بخواند، یک کلید رایگان از گوگل لازم است. کلید را در تنظیمات برنامه می‌گذاری؛ به کسی نده.

۱. برو به استودیو گوگل

با همان حساب گوگل‌ات این صفحه را باز کن:

aistudio.google.com/apikey

۲. کلید بساز

  1. اگر خواست، وارد حساب گوگل شو.
  2. دکمه Create API key را بزن (یعنی ساخت کلید).
  3. اگر پروژه خواست، همان پروژه برنامه را انتخاب کن.
  4. یک متن طولانی که معمولاً با AIza شروع می‌شود می‌دهد. همان کلید است.
  5. کپی کن.

۳. در برنامه بگذار

  1. برگرد به برنامه → تنظیمات ⚙
  2. بخش «خواندن فاکتور از عکس»
  3. کلید را بچسبان و ذخیره کن.

اگر کار نکرد

  • اول در برنامه ببین کدام مسیر جواب می‌دهد: تنظیمات ⚙ → «خواندن فاکتور از عکس» → آزمایشِ اتصال. نتیجهٔ هر دو مسیر (گوگلِ مستقیم و پل) با عدد و دلیل نوشته می‌شود.
  • اگر در ایران هستی، فیلترشکن را روشن کن: سرویسِ هوش مصنوعیِ گوگل به ایران سرویس نمی‌دهد. توجه کن که ورود به گوگل و همگام‌سازی درایو این محدودیت را ندارند؛ پس اگر لاگین کار می‌کند ولی هوش مصنوعی نه، دلیلش همین تفاوت است، نه خرابی کلید.
  • اگر با فیلترشکن هم گفت «منطقه پشتیبانی نمی‌شود»: سرور یا کشورِ فیلترشکن را عوض کن. گوگل آی‌پی‌های اشتراکیِ فیلترشکن و سرور را گاهی به منطقهٔ دیگری نسبت می‌دهد، برای همین یک سرورِ دیگر معمولاً مشکل را حل می‌کند.
  • اگر کلید را محدود کرده‌ای، این آدرس را در محدودیت کلید اضافه کن: https://taraz-app.github.io
  • کلید را در چت برای کسی نفرست.
  • رایگان است تا سقف روزانه گوگل؛ اگر گفت سهمیه تمام شده، فردا دوباره امتحان کن.

عکس فاکتور برای خواندن به سرور گوگل فرستاده می‌شود.

Key for reading receipts from photos

To let the app read a receipt photo, you need a free key from Google. You paste the key into the app's settings; don't share it with anyone.

1. Open Google AI Studio

Open this page with your Google account:

aistudio.google.com/apikey

2. Create a key

  1. Sign in to Google if asked.
  2. Tap Create API key.
  3. If it asks for a project, pick any (or the default one).
  4. You'll get a long string that usually starts with AIza. That's the key.
  5. Copy it.

3. Paste it into the app

  1. Go back to the app → Settings ⚙
  2. Section "Read receipts from photos"
  3. Paste the key and save.

If it doesn't work

  • First check which route answers: Settings ⚙ → "Read receipts from photos" → Test connection. It reports both routes (direct to Google, and the bridge) with the status and Google's own reason.
  • If you're in Iran, turn on a VPN: Google's AI service doesn't serve Iran. Google sign-in and Drive sync have no such limit — so if login works but the AI doesn't, that difference is the cause, not a broken key.
  • If it still says the location isn't supported with a VPN on: switch the VPN server or country. Google sometimes classifies shared VPN/server addresses as a different region, so another server usually fixes it.
  • If you restricted the key, add this origin to its allowed list: https://taraz-app.github.io
  • Never send the key to anyone in a chat.
  • It's free up to Google's daily limit; if it says the quota is exhausted, try again tomorrow.

The receipt photo is sent to Google's servers to be read.
